#+title: Free Software

Free software does not have to be free as in free beer.
It's about user freedom often referred as libre from the french translation.

* Free Software Foundation
There are a lot of organisations under the umbrella of the Free Software
Foundation around the whole world.
The mother foundation in the United States is the [[https://www.fsf.org/][Free Software Foundation]].
The [[https://fsfe.org/freesoftware/][Four Freedoms]] defined are to use, study, share and improve source code of
any software/program.
To guard these principles, several licenses like the [[https://www.gnu.org/licenses/gpl-3.0.en.html][GPL]] were introduced
together with the [[https://www.gnu.org/licenses/copyleft.en.html][Copyleft]] principle.
The Free Software Foundation has the goal to spread awareness, bring user
freedom to the people and help them to get [[id:8c32cdfa-a145-4a17-8d71-80e9d480fcdd][Digital Independence]] and [[id:40e9cc38-ea86-4cf5-aea5-275873c26885][Privacy]] for
their piece of mind.
This is done by sponsoring the [[https://www.gnu.org/][GNU]] project for example, which is used a lot
especially with things like the gnu-coreutils or the [[https://www.gnome.org/][GNOME]] desktop environment.
GNU is free software mainly to be used with the Linux kernel in GNU/Linux
operating systems.
Because there should not be a point of single failure, there are also projects
like [[https://www.gnu.org/software/hurd/][GNU Hurd]] to make more freedom respecting options.

In addition, there are a lot of distributed daughter foundations and communities
around it for example the [[https://fsfe.org/][Free Software Foundation Europe]].
They have a lot of important projects, which they try to push in the public
sector and politics like:
- [[https://fsfe.org/activities/publiccode/publiccode.en.html][Public Money, Public Code]]
- [[https://fsfe.org/activities/deviceneutrality/index][Device Neutrality]]
- [[https://fsfe.org/activities/routers/routers.en.html][Router Freedom]]
- [[https://fsfe.org/activities/android/android.en.html][Free Your Android]]
- [[https://www.fsf.org/campaigns/fight-to-repair][Fight to Repair]]
- [[https://reuse.software/][REUSE Software]]

* Apps
The simple way to find free software is to use the software center used by the
[[id:507abdf6-b785-4b29-9271-c365c5fe1a6c][GNU/Linux]] operating system.
Often this is the [[https://apps.gnome.org/Software/][Gnome Software Center]] for [[https://www.gnome.org/][GNOME]] or
[[https://apps.kde.org/discover/][KDE Discover]] for [[https://kde.org/][KDE]].
These software centers often also distribute Flatpaks or Snaps.
There is also the distribution agnostic app store [[https://flathub.org][FlatHub]], which delivers
isolated app containers as Flatpaks.
Especially for Ubuntu users, there is also the [[https://snapcraft.io/][Snap Store]] as an alternative to
Flatpaks, although this store cannot be distributed and relies on [[https://canonical.com/][Canonical]] with
some advantages and disadvantages as a result.
For power users various package management systems are available.

There is often an option to filter for free software or to allow only specific
licenses like GPL.
Not all GNU/Linux distributions offer FLOSS (Free Libre Open-Source Software)
only.
To be sure to strictly only install and use free software, use a
[[https://www.gnu.org/distros/free-distros.html][Free Gnu/Linux Distribution]] recommended by the [[https://www.gnu.org/][GNU]] project without binary blobs.
